1. What does fetch() actually return immediately, and why isn't that your data? What is a Promise a placeholder for?
    fetch() returns a Promise right away
    The Promise is a placeholder for the data that will come back later from the server

2. What does the await keyword do, and why can it only be used inside a function marked async?
        await pauses the async function until the Promise finishes
        It can only be used inside an async function because async allows the function to wait for Promises

3. fetch()'s Promise resolved successfully for a misspelled Pokémon name — it didn't reject. So why did the page show a "not found" message instead of crashing? What check made that possible? Why is this exact mistake one you're likely to see again in a real job?
    The code checked response.ok. If it was false, the code threw an error and showed the "not found" message
    This matters because fetch() does not automatically fail for a 404 error

4. Why do you need two awaits in your search function — one for fetch(...) and one for response.json()? What is each one waiting on?
    The first await waits for the server to respond
    The second await waits for the response data to be turned into JSON

5. Where did map() show up in this IC, and how is what it did here similar to how you used it (or forEach()) on the array of products in IC14?
    map() was used on the Pokémon types to get each type name
    It is similar to IC14 because it goes through each item in an array and uses the information from each item
