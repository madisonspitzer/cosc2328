1. What does an external stylesheet do, and why is keeping CSS in its own file better than putting styles inside the HTML?
    It keeps the page design in a seperate CSS file, which makes the HTML cleaner and easier to edit.

2. In a CSS rule, what is the selector and what is the declaration (property: value;)? Give one example from your file.
    The selector chooses what to style. The declaration says how to style it.

3. What is the difference between a class selector (.card) and an id selector (#intro), and when would you use each?
    A class like .card can style many elements. An id like #intro is for one specific element.

4. Both the <link> (css/ic5.css) and the <img> (images/photo.jpg) use relative paths. What does each one point to, relative to where ic5.html lives?
    css/ic5.css points to the CSS file inside the css folder. images/photo.jpg points to the picture inside the images folder.
